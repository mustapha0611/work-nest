# Architecture Decision Records

Record important decisions as numbered Markdown files, for example `0001-package-manager.md`.

Suggested template:

```md
# ADR 0001: <Decision title>

- Status: Proposed | Accepted | Superseded
- Date: YYYY-MM-DD

## Context

What problem or choice prompted this decision?

## Decision

What are we choosing?

## Alternatives considered

What else could work, and why was it not selected?

## Consequences

What benefits, limitations, and follow-up work does this create?
```
